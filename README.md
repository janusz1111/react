# react
Pobierz plik App.jsx i w nowym projekcie react zapisz go w folderze src.
To samo zrób z plikiem App.css (lub dostosuj istniejący plik, opisując klasy z nowego pliku App.jsx)
Wróć do głównego folderu aplikacji i w terminalu wykonaj polecenie: npx vite
Przejdź do przeglądarki na wygenerowany adres: zwykle localhost:5173
Przeczytaj zadanie i zmodyfikuj plik src/App.jsx tak aby pojawiły się na stronie twoje dane.
